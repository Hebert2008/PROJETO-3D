# Plataforma de Conexão para Impressão 3D 🖨️

## 📖 Contexto do Projeto
Este projeto foi desenvolvido como requisito para a disciplina de Programação Orientada a Objetos (POO). O sistema propõe uma solução para um problema real no mercado de manufatura sob demanda: a ociosidade de impressoras 3D de hobbyistas e pequenos empreendedores versus a alta demanda de clientes que precisam de peças rápidas ou de alta precisão. A plataforma atua como uma ponte especializada, conectando "Solicitantes" (clientes com urgência ou necessidades técnicas específicas) a "Impressores" (donos de máquinas em busca de rentabilizar seu tempo ocioso). Um diferencial técnico e de negócio do sistema é a capacidade de gerenciamento de **produção parcial**, permitindo que diferentes impressores assumam frações de um mesmo pedido grande, democratizando o acesso e otimizando o fluxo de trabalho.
